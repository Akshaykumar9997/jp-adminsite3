# Local browser-test fixture

`flower.mp4` is the small H.264 flower video used by MDN's HTML video examples.
Source: https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4
License: CC0 (the source's `cc0-videos` example collection).

Used only when headless Chrome advertises MP4 recording but returns an empty recording.
It is never uploaded to production by the test harness.
